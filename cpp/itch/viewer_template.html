    How this was made

      Nasdaq publishes every order event on its exchange as a binary feed called ITCH. A C++ program read the whole day's file and applied each add, execution, cancel and replace to an order book for every stock, the same price-time-priority book this repo builds and benchmarks. This page plays back the rebuilt book for one stock.

      Lit: a displayed order traded. Hidden: a non-displayed order traded. Cross: the opening or closing auction.
