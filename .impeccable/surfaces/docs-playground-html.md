# Surface: order book site (replay + strategy playground)

Mode: operate. Audience: recruiters/interviewers and technical peers, equally; both explore hands-on. Task: scrub the AAPL 2019-01-30 replay; set filter, activity rate, latency, action and placement in the playground and read the result, the honest scorecard, and the model and generalisation evidence. Constraints: static pages in docs/; numbers only from generated data; owner identity (name, GitHub; LinkedIn and resume links pending). Unresolved: LinkedIn and resume URLs.

## Direction contract

THESIS: The matching engine replaced the Chicago pit; the site wears the pit's identity system on a clean working screen. It refuses the category default, a dark trading terminal of green and red on charcoal.

OWN-WORLD: Pale card-stock grey ground, ink-black type and rules. Four firm-jacket colours carry the four filters at full saturation: kelly green, royal blue, goldenrod, vermilion; graphite for "no filter". Heavy condensed block capitals for badges and headings, a plain workhorse sans for UI, tabular figures everywhere.

STORY: Within one screen the visitor knows this is a real exchange order book rebuilt from Nasdaq data, sees a strategy's afternoon, changes a setting and watches the result move, then reads which results held up and which did not.

FIRST VIEWPORT: Top bar: project name, owner, tabs Replay / Playground / Method, GitHub link. Playground: left rail of controls (filter badges, activity slider with the tuning-hour pick, latency, action, placement); main column: five-number scoreboard, then the PnL curve with the selected badge against no filter; right column: the scorecard table at tuning-hour picks.

FORM: grounded list position 3 of 7 (Chicago open-outcry pits). Signature move: pit badges, three-letter acronym chips in jacket colours (OFF, IMB, NXT, LAT, TOX), the same chip in controls, chart legends, table rows and the replay's trade tape side markers. seed:0919264b28246e26
